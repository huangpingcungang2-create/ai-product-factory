# AI Product Factory

Turn business ideas into:

✅ Product Requirements (PRD)

✅ System Architecture

✅ GitHub Issues

✅ Development Plans

## Example

### Input

Build a CRM for real estate agencies.

### Output

- Product Requirements Document
- System Architecture
- GitHub Issues
- MVP Roadmap

## Why

Most products fail before coding starts.

AI Product Factory helps founders and developers turn ideas into executable plans.

## Features

- PRD Generation
- Architecture Generation
- GitHub Issue Generation
- Development Planning
